# 同一 Skill 对不同文案的自适应示例

## 1. 家长教育观点

文案重点：孩子是否应该尽早学习编程。

预期策略：人物观点为主；关键概念用对比图；家长顾虑用生活化画中画；结尾保留人物。不会自动加入大量代码录屏。

## 2. AI 工具操作教程

文案重点：如何用某个 Agent 整理研究资料。

预期策略：成品先行；真实界面和输入输出为主；步骤使用局部放大；人物只在开头承诺和结尾复盘出现。不会用“家长和孩子看电脑”的泛场景替代操作。

## 3. 亲子项目故事

文案重点：孩子从一个兴趣问题做出小工具。

预期策略：具体物体、提问、过程和成品；亲身叙述时保留人物；抽象步骤用简洁流程图；必要时才生成情境视频。

## 4. AI 新闻解读

文案重点：某项新模型或政策对普通家庭的影响。

预期策略：来源、发布日期、关键变化、影响路径和个人判断；真实资料卡优先；不使用伪新闻截图。

## 5. 方法清单

文案重点：家长暑假可以做的三件事。

预期策略：先建立三项总览；每一项只选一个主视觉；避免每句话换图；结尾回到人物做行动号召。

这些示例说明视觉语法会随文案改变，具体素材不能跨视频硬套。
