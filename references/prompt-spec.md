# 图片与视频提示词规范

## 1. 图片提示词

每条图片提示词至少包含：

1. **用途与占屏方式**：全屏、画中画、背景、信息图底图；
2. **主体**：年龄范围、物体、数量、关系；
3. **动作/状态**：正在做什么，而不是只写“一个孩子”；
4. **环境**：家庭书桌、教室、运动馆、电脑桌面等；
5. **构图**：近景/中景/俯拍、主体位置、预留文字区；
6. **光线与质感**：自然光、温暖、纪实、产品摄影等；
7. **比例与分辨率意图**：默认 9:16；画中画可指定 4:3 或 1:1；
8. **后期要求**：不生成文字、Logo、水印；
9. **负面约束**：避免多余手指、乱码界面、赛博元素、夸张表情等。

### 图片提示词模板

```text
用途：[全屏/画中画/背景]，用于口播中“[锚点]”。
主体与动作：[具体人物/物体]正在[动作]。
环境：[真实场景与必要道具]。
构图：[景别、机位、主体位置、留白区]。
光线与风格：[纪实/商业摄影/温暖教育感等]。
画幅：[9:16/4:3/1:1]，高细节，适合短视频剪辑。
禁止：任何文字、Logo、水印、伪造软件界面、机器人、全息投影、赛博朋克、畸形手部、过度磨皮。
```

对信息图：只生成无字图标、节点、箭头和背景。准确中文标签在后期添加。

## 2. 视频提示词

每条视频提示词必须能直接复制到视频生成工具，至少包含：

1. 生成总时长与成片取用时长；
2. 画幅与帧率意图；
3. 单一清晰主体；
4. 一个可稳定生成的主要动作；
5. 场景与道具；
6. 起始构图和结束构图；
7. 镜头运动；
8. 光线、色调和真实感；
9. 与前后镜头的连续性要求；
10. 明确负面约束。

### 视频提示词模板

```text
生成一段 [6] 秒、9:16 竖屏、自然写实的 B-roll。剪辑实际取用约 [3–4] 秒。
场景：[地点、时间、背景]。
主体：[人物年龄范围/物体]，正在进行一个明确动作：[动作]。
镜头：从[起始景别与位置]开始，[缓慢推近/轻微横移/固定机位]，最终停在[结束画面]；运动稳定，无突然变焦。
光线与风格：[自然窗光/温暖纪实/干净教育科技感]，肤色与材质真实，景深适中。
连续性：主体外观、服装、道具和屏幕内容在整段保持一致；画面上方/侧边为字幕或画中画保留空间。
禁止：画面内文字、Logo、水印、伪造软件 UI、机器人、全息投影、赛博城市、夸张科幻光效、多余人物、畸形手指、突然换脸、镜头抖动、速度拉伸。
```

### 多镜头需求

除非生成模型明确支持分镜控制，否则不要把 4–5 个镜头塞进一个提示词。优先拆成多个独立素材，以 `S08A`、`S08B` 命名，后期剪辑组合。

## 3. 真实录屏说明

真实录屏不写“生成提示词”，而写：

- 操作环境与页面；
- 录制前准备；
- 鼠标点击/键盘输入顺序；
- 每一步建议停留秒数；
- 是否需要局部放大；
- 账号、文件名、通知、头像和路径的遮挡；
- 目标成片时长；
- 可替代素材。

## 4. 素材搜索关键词

同时提供：

- 中文意图词；
- 英文素材库关键词；
- 2–4 个组合查询；
- 排除词，例如 `-robot -hologram -cyberpunk`。

不要只给一个宽泛词，例如“AI”“孩子”“学习”。
