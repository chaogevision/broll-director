# 事实、版权、隐私与儿童画面规则

## 1. 事实核验

以下信息在制作当天重新核验并记录日期：

- 价格、套餐、汇率和折扣；
- 产品是否仍存在、正式名称与 Logo；
- 软件界面和功能；
- “最强、顶级、第一”等比较性表达；
- GitHub 项目许可证和运行要求；
- 数据、研究结论和新闻。

无法核实时，在时间轴中标记 `待核实`，不要把它做成确定事实卡。

## 2. 软件和品牌

- 使用真实截图/录屏，并尽量取自用户自己的合法账号或官方公开页面；
- 不用图像模型伪造产品 UI、套餐页、Logo 或新闻页面；
- 对界面中的用户名、邮箱、头像、文件路径、API Key、聊天历史和通知做遮挡；
- 素材清单记录来源 URL/文件与抓取日期；
- 使用 Logo 时不改变比例、颜色和文字。

## 3. 外部图片和视频

- 优先用户自有素材或明确允许商业使用的素材；
- 记录素材平台、作者/条目、许可和下载日期；
- 不以“网上能搜到”为可用依据；
- 需要署名时在说明或片尾落实。

## 4. 儿童

- 不使用未经监护人同意、可识别身份的真实儿童素材；
- 生成儿童画面时使用非特定、虚构人物，不要求复制真实孩子面貌；
- 不表现危险操作、羞辱、过度压力或不适当成人化场景；
- 画面重点放在好奇、合作、探索和作品，而不是制造“神童”承诺。

## 5. 生成素材标识

项目内部素材清单必须标记：

- `REAL`
- `STOCK_LICENSED`
- `GENERATED`
- `GRAPHIC`
- `MOCKUP`

如果示意 UI 可能被观众误解为真实产品，画面内或说明中标注“示意”。
